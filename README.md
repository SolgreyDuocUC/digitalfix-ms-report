# DigitalFix - Microservicio de Reportería (ms-report)

Microservicio encargado de la agregación de métricas, reportes operativos e informes analíticos del sistema DigitalFix.

## Puerto

Puerto reservado para desarrollo local: `8086`, único dentro del ecosistema (ver la [tabla de puertos](https://github.com/SolgreyDuocUC/digitalfix-infrastructure#86-puertos-de-los-microservicios) en `digitalfix-infrastructure`). Al implementar el servicio, configurarlo con la variable `PORT` del `.env`.
